Contrato

Mismo MultiSelect de Estado, Persona y Cuenta, con opciones de /categories.
OrigenGET /categories · 10 categorías hoy, todas isDefault.
GrupobudgetGroupId → nombre del grupo de presupuesto. El JSON solo trae el id; los nombres del diseño (Esenciales, Estilo de vida, Desarrollo, Social) son provisionales hasta resolverlos desde la API de grupos.
Opciónvalue = id · etiqueta = name · color = color · icono = icon (lucide: home, utensils, gamepad-2…).
OrdenGrupos en el orden del presupuesto; dentro de cada grupo, alfabético.
AnchoEl popover mide al menos 300 px y no corta nombres («Entretenimiento» completo).
Grupo con una sola categoríaSigue mostrándose como grupo (Social → Junta) para mantener la estructura.
Resumen1 = nombre · 2 = «A, B» · 3+ = «A, B +N» · grupo completo = nombre del grupo. Vacío = «Todas las categorías».
CasillasCirculares 18 px, iguales a Estado, Persona y Cuenta.
